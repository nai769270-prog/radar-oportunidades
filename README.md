# Radar de Oportunidades

Plataforma para detectar sinais públicos de necessidade e intenção, classificar oportunidades e apoiar conexão comercial responsável.

## MVP
- Dashboard de inteligência
- Busca de demandas e problemas públicos
- Score de oportunidade
- Evidência e origem do sinal
- Canais públicos de contato
- Base para enriquecimento B2B e CRM

## Pipeline
Fonte pública → sinal → normalização → classificação → score → oportunidade → enriquecimento → contato/CRM.

## Princípios
Usar fontes públicas e integrações permitidas. Não coletar dados privados ocultos, não contornar controles de plataforma e não automatizar spam.

## Desenvolvimento
```bash
npm install
npm run dev
```
